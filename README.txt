HALE'S MOTORSPORTS TECHNICIAN INSPECTION APP — V1

Files:
- index.html
- styles.css
- app.js
- manifest.json
- sw.js

V1 includes:
- Customer, phone, date, RO/invoice, technician
- Year, make, model, mileage, VIN
- License plate and registration state dropdown
- All inspection categories/items from the supplied 3-page Hale's technician inspection sheet
- Green / Yellow / Red status buttons
- Measurement / notes on every item
- Technician summary / recommendations
- Priority repairs
- Technician signature name and customer-advised status
- Automatic local draft saving on the device
- Inspection counts
- Print / Save-as-PDF customer report via browser print
- PWA manifest + offline service worker for installation when hosted over HTTPS

IMPORTANT:
Data is stored locally in the browser on that device. V1 does not yet sync to a server or cloud account. Clearing browser/site data can remove saved draft data.

To use as an installable iPhone PWA, host this folder on an HTTPS website, open it in Safari, then use Share > Add to Home Screen.
